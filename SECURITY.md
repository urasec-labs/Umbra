# Security Policy

Found a vulnerability in Umbra itself (e.g. report XSS, path traversal in the dashboard, secret leakage in reports)?
Please **do not open a public issue**. Use GitHub's *Report a vulnerability* (Security tab) or contact Uras AKAS via https://urasakas.com.

Scope notes: Umbra redacts secret values in findings and reports, and the dashboard binds to `127.0.0.1` only.
If you find a case where either promise breaks, that is exactly what we want to hear about.
